# E-Civil Registry Portal

## Description

E-Civil Registry Portal is a backend application built using NestJS for managing civil registry services.

## Technology Stack

- NestJS
- TypeScript
- Node.js

## Project Setup

Install dependencies:

```bash
npm install
```

## Run Application

Development mode:

```bash
npm run start:dev
```

Production mode:

```bash
npm run start:prod
```

## Application URL

```text
http://localhost:3000
```
